## 4. 平台变体

以下是有意的平台边界，不应被合并成运行时大量 `Platform.OS` 分支：

- `src/lib/storage.tsx` / `storage.web.tsx`；
- Chat 的 `.web.tsx`、`.ios.tsx`、`.android.tsx`、`.swiftui.tsx` 和 fallback 文件；
- 任何后续新增的平台文件必须保持相同公开导出和语义。

## 5. 新模块放置规则

- 只有页面入口：放 `src/app/**`。
- 一个页面内部的小展示块：放页面附近或现有 `src/components/<domain>`。
- 多页面共享且包含状态/流程的领域能力：放 `src/features/<feature>`。
- 后端访问：放 `src/api/<domain>`，不得在页面新建 Axios。
- 跨领域纯工具、Hook 或平台适配：放 `src/lib/**`。
- 通用交互原语：放 `src/components/ui/**`，同时补充组件测试。
