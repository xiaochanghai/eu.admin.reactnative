# 测试与交付门禁

> 状态：`CURRENT`\
> 返回：[文档索引](../README.md)

## 1. 通用最低门禁

所有代码任务至少执行：

```text
pnpm exec eslint <本次拥有路径>
pnpm exec prettier --check <本次拥有路径>
git diff --check
git status --short
```

不得用全仓 autofix 清理与任务无关的用户改动。若需要格式化，只格式化明确拥有文件。

## 2. 风险对应验证

| 变更                      | 最低追加验证                                                       |
| ------------------------- | ------------------------------------------------------------------ |
| 纯函数、Storage、API 转换 | 相关 Jest 定向测试                                                 |
| UI 组件                   | 相关组件测试 + Web/目标原生人工交互                                |
| Route/布局                | Web bundle + 入口/跳转/回退/直接 URL 回归                          |
| Auth/HTTP                 | 登录测试 + 401/网络失败/登出清理回归                               |
| Chat 客户端               | `attachment-picker`、`chat-storage`、`chat-api` 测试及流式取消回归 |
| Chat API                  | 鉴权、非法 body、附件限制、无 key、上游超时测试                    |
| Expo 依赖/配置            | `expo install --check` + `expo config --type public`               |
| 原生依赖/权限             | 目标平台 Development/Release Build；必要时 prebuild diff           |
| OTA/runtimeVersion        | 新旧 Binary 兼容矩阵和目标 channel 检查                            |

## 3. 常用命令

```text
pnpm run type-check
pnpm run test
pnpm run test:ci
pnpm run lint
pnpm run check-all
pnpm run build:web
pnpm exec expo install --check
pnpm run doctor
pnpm run e2e-test
```

优先运行定向 Jest，例如：

```text
pnpm exec jest src/features/chat/chat-api.test.ts --runInBand
```

`doctor` 使用 `npx expo-doctor@latest`，可能需要网络。Maestro E2E 需要已安装工具和可运行目标，不应
在不具备环境时假装通过。

## 4. 平台验收

- Web：检查 Bundle、窄屏/宽屏、浏览器回退、直接 URL、刷新和控制台错误。
- iOS：检查 Safe Area、键盘、手势、Sheet、状态栏、权限和 Release Splash。
- Android：检查系统返回键、权限、Edge-to-edge、键盘、下载/安装和 Release Splash。
- 自定义原生模块：使用 Development/Release Build；Expo Go 结果无效。

## 5. 文档任务

纯文档任务无需运行 Jest、TypeScript 或应用构建，但必须验证：

- 所有相对链接的目标存在；
- 文档中的源码路径、脚本名和配置键存在；
- `CURRENT` 与实际代码一致，未来内容明确标 `PLANNED`；
- `git diff --check` 无空白错误；
- 未覆盖用户已有改动。

## 6. 交付报告

交付应准确说明：修改的行为或文档、关键文件、已运行检查及结果、未运行的真机/远端检查、已有
基线失败和发布前置条件。`Web export 通过` 不等于 Android/iOS 原生模块已验证；`INTEGRATED` 也
不等于已发布。
