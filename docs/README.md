## 3. 文档分层

- L0：`AGENTS.md`，任务路由和强制约束。
- L1：`design.md`、本索引，系统设计摘要和导航。
- L2：`docs/架构/**`，跨模块稳定事实与生命周期。
- L2：`docs/模块/**`，模块 owner、入口、依赖和测试锚点。
- L2：`docs/开发/**`，所有任务共同遵守的工程门禁。
- L3：专题文档，例如 `chat-ai.md`。

## 4. 状态词

- `CURRENT`：与当前代码和配置一致。
- `PLANNED`：尚未实现，不得当作现有能力。
- `APPROVED`：方案已确认，但不代表已集成或发布。
- `INTEGRATED`：代码形成完整纵向切片，不代表已发布。
- `SUPERSEDED`：已被新设计替代，仅保留历史。
- `HISTORICAL`：历史材料，不作为当前实现依据。
